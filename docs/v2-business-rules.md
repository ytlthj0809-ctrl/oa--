# V2 业务规则

- 日数据首期只支持比心，业务日期从文件名识别并在预览时确认。
- `ID` 必须为 1–20 位纯数字，同一文件中重复 ID 会阻止整批导入。
- 每位主播金额按 `总星动值 × 0.0058 元` 四舍五入到分；零收入 ID 仍永久获得注册资格。
- 未注册收入按比心 ID 留存，注册成功后自动归集历史收入。
- 同一业务日期只能有一个生效批次；修正必须整体删除后重新上传。删除保留审计，资格不撤销。
- 删除前若相关收入已被提现或其他资金动作占用，必须阻止删除。
- 超管可配置每周开放规则和特殊日期；特殊日期优先。初始默认每天开放。
- 提现时间固定为北京时间 08:00（含）至 16:00（不含）；当天 08:00 后不可修改当天规则。
- 单笔最低 100 元，无固定上限，同日可提交多次；提交时直接扣减余额。
- 16:00 后才能导出当日云账户 Excel。必须导出后才能驳回或将剩余记录全部标记成功。
- 驳回原因可空，驳回立即恢复余额；原申请日不得再次提交，下一个开放日可重新提现。
- “剩余全部成功”仅作用于当前日期已导出且仍待打款的记录，成功不可撤销。
- 手工余额调整必须填写原因，允许形成负余额；后续收入自动抵扣。
- 管理员会话最长 8 小时，连续 30 分钟无操作失效；所有管理和敏感查看动作永久审计。
